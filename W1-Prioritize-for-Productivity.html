Part I

The Build Loop

Every effective AI tool follows the same 5-phase pattern. Keep this mental model in mind as we complete today's builds.

1. Align
Determine goals & what good looks like
2. Capture
Commit your rules to a clear spec
3. Build
Encode spec into a saved skill
4. Test
Run real input through the skill
5. Refine
Give feedback to sharpen over time
Part II

Prioritization First

The Trap of Moving Faster

Prioritization must come before automation. Speed alone is counterproductive if applied to the wrong tasks.

"The technologies we use to try to get on top of everything always fail us in the end, because they increase the size of everything of which we're trying to get on top."
— Oliver Burkeman, Four Thousand Weeks

The 10x Test Exercise

  • Audit past week: Generate 10 quick, specific bullets of actual tasks and meetings (ask AI to draft this from your notes/calendar).
  • Name goals: List your key goals for the current quarter or year.
  • Apply the 10x filter: For each task, ask: "If I got 10x better at this, would I be 10x more effective at hitting my goals?"
  • Bucket non-10x tasks: Identify what could have been a polite "no", and what is unavoidable work that needs its execution time shrunk.

I'm building a personal "email style guide" so that when AI helps me write emails, they sound like me. I'm pasting in 5–10 recent emails I've sent below. Read across them and build me a style guide that captures: - Sentence length and rhythm (do I write short or long, choppy or flowing?) - How I open emails (or don't) - How I close emails (sign-offs, last lines) - How I push back, disagree, or say no - How I ask for things - Words and phrases I use a lot - Things I never do (e.g., never use "Hope this finds you well") - Tone — formal vs. casual, warm vs. terse, direct vs. hedged Output the guide as a clean, reusable markdown file I can paste into the Instructions field of an agent called "email-style". Build Step 3: Weekly Update Writer Agent

Follow this 3-prompt sequence to construct an automated manager status update generator.

STEP 1: Define Manager Expectations

I'm a [your role] at [company & team] and I send a weekly status update to my manager every Friday. Before writing anything — what does a manager actually need from a weekly update? What are they scanning for, what makes them stop reading, and what's the difference between an update that gets skimmed vs. one that changes how they think about my team? Be specific.

STEP 2: Extract Criteria List

Take the criteria you just listed and output them as a clean, reusable bulleted list I can save and paste into another prompt. Just the list — no commentary.

STEP 3: Generate System Prompt

I want to build a "weekly-update" Copilot agent — a reusable assistant that turns a screenshot of my calendar into a weekly status update for my manager. Success criteria for what good looks like: [Paste bulleted list from Step 2] When someone pastes a calendar screenshot, it should: 1. Read the calendar and identify what was actually worked on. 2. Turn that into a weekly status update hitting the success criteria above. 3. Match my email voice rules so it sounds like me. Generate a clean, reusable system prompt as a markdown file for a Copilot agent named "weekly-update". Bake the success criteria and voice rules directly into the system prompt. Extra rules: don't pad, lead with the most important item, flag risks clearly, zero filler.
Part IV

Session Summary & Takeaways

Impact Over Speed

AI is most valuable when it lets you say no to low-impact work and shrink unavoidable friction — not when doing more noise faster.

Debug the Loop

When an AI tool fails, ask: "Which phase of the Build Loop (Align, Capture, Build, Test, Refine) did I skip or rush?"

Context is King

Every agent needs explicit Success Criteria and clear personal Context to generate high-grade outputs.

Iterative Mindset

Get a rough version working first, test it on real calendar/email data, and refine through immediate feedback.
